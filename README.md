🐍 Snake Game – HTML Single File Version
HTML + CSS + JavaScript 한 파일로 구성된 스네이크 게임입니다.
브라우저만 있으면 어디서든 실행되며, GitHub Pages로도 바로 플레이할 수 있습니다.

📘 프로젝트 소개
이 스네이크 게임은 HTML, CSS, JavaScript가 모두 한 파일(snake_min.html) 안에 포함된 단일 구조입니다.
추가 라이브러리 없이 작동하며, 교육 및 실습용으로 매우 적합합니다.
